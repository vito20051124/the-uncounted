# 《無籍者》The Uncounted

一款文字生存沙盒。**你在半夜十二點下樓買宵夜，回程時一陣怪風，睜眼已在異世界的一條巷子裡，身上只有出門時帶的三樣東西。**

你不會魔法、治不好傷、沒有任何政體在數你。

> 這不是一個回家的故事，是一個從「沒有人在乎你是誰」爬到「有人在乎你死活」的故事。

TypeScript ＋ Preact ＋ Vite，**全離線、無 CDN**。目前是 P0.5 垂直切片：鹵港六個城區、14 個遊戲日。

---

## 這個專案在做什麼

它以 Degrees of Lewdity 的**架構**為參照，然後**刻意反向設計**：

| | DoL | 本作 |
| :-- | :-- | :-- |
| 弧線 | 從完整走向崩壞 | 從一無所有往上爬 |
| 核心數值方向 | 累積傷害 | 累積根基 |
| 張力來源 | 「我還能撐多久」 | **「我好不容易有的東西會不會沒了」** |
| 性的地位 | 骨架 | **點綴**——整段移除後遊戲仍須完整可玩 |
| 地圖 | 靜態底圖，點一下瞬移 | **有向圖**，邊帶時間／體力／風險／高程，會隨潮汐與日夜改變 |

設計憲法在 [`design/00_pillars.md`](design/00_pillars.md)，包含三條明確的反 DoL 條款。

## 關於那些 `canon/**` 引用

`design/` 底下大量出現 `canon/07 §4.1`、`world/catalogs/hollow-flora.md` 這類引用。

**它們指向一份未包含在本倉庫的私有世界觀語料**——一部原創西式歐陸中世紀高奇幻世界觀《瑟瑞恩 Serein》（約 324 條目、178 萬字元）。本作的每一個數值都從那份語料的既有錨點反推，而不是憑手感填的：

- 碼頭工日薪 **15 銅**、客棧單間 **12 銅/夜**、一餐 **3 銅** → 相減得 **0**。**收支恰好歸零，這不是設計出來的，是既有物價自己算出來的。**
- 傷口化膿率 **34%**（未處置）／**21%**（草藥處置後）
- 貨幣 **1 金帝 ＝ 240 銅**（磅-先令-便士式，非十進）

所以那些引用讀起來會是斷鏈——這是刻意的，不是漏檔。每個數值旁邊都有 `canon:` / `derived:` / `invented:` 標記，建置期會統計 `invented` 比例（目前 **0%**）。

## 架構

```
src/engine/     純 reducer，零 UI 依賴。(state, action) => state'
  types.ts        GameState 與內容 schema
  clock.ts        時間與需求衰減（★ 每個速率都指得出正典錨點）
  body.ts         傷病鏈與剝奪計時
  mind.ts         理智與日界結算
  map.ts          路線列舉（★ Pareto 前緣，不是最短路）
  events.ts       事件候選與加權抽選
  cond.ts         唯一的條件求值器
  rng.ts          無狀態 seeded RNG
data/           純資料。46 事件、5 NPC、6 節點、14 路段、13 物品、3 工作
design/         設計文件（等同遊戲側 canon）
scripts/        建置期驗證與跑分
```

### 九條紀律

1. **引擎零 UI 耦合**——`src/engine/**` 不 import 任何 Preact
2. **內容零邏輯**——`data/**` 是純資料，敘事文本不得寫進 `.ts`
3. **金錢一律整數銅**（1 金帝 ＝ 240 銅，非十進，絕不以浮點儲存）
4. **時間分兩層**——引擎只認整數分鐘；鐘點映射是資料
5. **純 reducer ＋ `ledger` 從第一行程式碼就寫**
6. **無狀態 seeded RNG 分流**——不維護游標，新增事件不會位移後續序列
7. **所有條件走同一個求值器**
8. **禁止小數分鐘**
9. **node id 必須帶城市前綴**

## 值得一讀的部分

`design/04_roadmap.md` 記錄了六輪開發中**實際玩下去才撞到**的缺陷，包含幾個我認為有普遍性的：

- **「睡覺必死」**——需求在睡眠期間以清醒速率衰減，而一夜 572 分鐘 > 水分歸零的 480 分鐘。任何人只要睡覺就必定醒來時脫水歸零。
- **「宣告不等於驗收」**——註解宣稱「反推自每日 1.5–2 磅主食」，但填進去的 720 分鐘**把一天當成 720 分鐘算**，而一天是 1440。
- **一道 2% 擦傷的 14 日致死率 95.6%**——`38.5%` 是「嚴重創傷」的**一生一次**機率，被實作成**每夜重擲**，而傷口永不痊癒。註解、UI、測試三處同時宣稱那是 5.2%。
- **兩個假綠燈測試**——一條靠手動注入 `hungryTicks: 3`（一個對局中不可達的狀態）通過；另一條在測試檔裡自己重寫一遍算式並驗證那個算式，**完全沒有呼叫被測函式**。
- **玩家付出稀缺資源換到精確的 0**——事件裡的治療選項寫的是全域 flag，而引擎讀的是 `treated:<傷口id>:<方式>`。玩家付了錢、燒掉敷料，化膿率一點都沒降，而遊戲當場回饋「你成功了」。

驗收標準也從「死亡率落在某個區間」改成了**「粗心的人必須死得明顯更多」**——若兩者差不多，就表示玩家的決定不影響結果，那才是真正的失敗。

```
小心政策   死亡率 11.2%   結局理智中位數 70   結局清潔中位數 61
粗心政策   死亡率 22.4%   結局理智中位數 40   結局清潔中位數  0
```

## 內容界線

本作為成人向生存遊戲，**但本倉庫不含露骨性描寫**。性與親密在架構上被刻意限制為「回復理智的其中一條分支」，與「吃到一頓熱的」「睡在有門板的房間」並列，且**不得另立計量、不得更有效率**——這由煙霧測試 ㉘ 機械化驗證（掃 state 與全部資料，確認不存在任何慾望槽）。

不含、也不會加入涉及未成年或非合意情境的內容。
