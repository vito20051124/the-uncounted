# 05 · 主線《名字》

> 本檔定義《無籍者》的主線脊椎。上位法：`00_pillars.md`（遊戲憲法）與 `canon/07_the_outsider.md`（世界側地基）。
> 兩者衝突時以 canon 為準。

---

## 0 · 為什麼主線不是「回家」

`canon/07` §2 把回家這條路**永久封死**：全境 0 名活著的樞階，且明文禁止在任何地方寫出回家的伏筆。

這不是限制，這是**本作與 DoL 最根本的分野**。DoL 沒有主線，因為它的弧線是下墜——下墜不需要目標。本作的弧線是往上爬，而爬需要一個**爬得到的**目標。

> **回家是不可能的，所以主線必須是「留下來」。**

而「留下來」在這個世界有一個具體、可量化、canon 直接給定的形式：

> **`canon/07` §6：她是普查未及者——2,389 名沒有被任何政體數進去的人之一。**
>
> 主線的問題因此不是「我怎麼回去」，而是 **「我怎麼從一個沒有被數的人，變成一個被數的人」**。

主線名稱 **《名字》**。它同時是馬斯洛第二層（安全）的具體障礙物：**沒有籍，就沒有租約、沒有工牌、沒有訴訟權、沒有醫療、遇到城衛只有扣留。**

## 1 · 三層目標與五章

| 馬斯洛層 | 遊戲目標 | 章 |
| :-- | :-- | :-- |
| ① 生理 | 今天不要餓死 | **第一章 落地** |
| ② 安全 | 有一個屬於你的名字 | **第二章 殘滓** → **第三章 名字** |
| ③ 歸屬 | 有人會在你不在時提到你 | 貫穿；由三條關係線承載 |
| ④ 尊重 | 有一門別人需要你的手藝 | **第四章 手**（P2） |
| ⑤ 自我實現 | 安家／立業／平凡地度過一生 | **第五章 結局**（P2） |

**P0.5–P1 的範圍是第一至第三章。** 第四、五章列入 P2，不在本輪實作。

## 2 · 章節

### 第一章 · 落地（第 1–3 日）

**目標**：不要死。認識這座城的形狀與三個人。

已實作。開場即抵達巷子，`ev-dross-trace` 埋下主線第一顆種子（牆角的結晶）。

**出章條件**：認識三名 NPC 中至少一名，且活過第 3 日。

### 第二章 · 殘滓（第 3–8 日）

> **這一章的功能是：讓她發現「她的到來留下了證據」，而證據會被別人看見。**

`canon/07` §3 的守恆律規定：那場誤觸發**消耗了靈血，因此在抵達點留下了可測量的殘滓**。這是全世界唯一與她有關的物證。它不能證明她從哪裡來（§3.1 抵達點隨機、與裝置無空間關係），但它足以讓懂行的人知道**這裡發生過元血之世等級的事**。

三條互斥的處置，各自導向不同的第三章開場：

| 處置 | flag | 後果 |
| :-- | :-- | :-- |
| **賣掉**（灰棚巷黑市） | `dross-sold` | 立刻拿到一筆遠超日薪的錢（**第二章唯一的快錢**），但殘滓從此不在你手上，且買家記住了你 |
| **給石啞看** | `dross-identified` | 寂裔的無血工藝能辨識它。他不問來歷（族規），但他從此知道你不是普通的靈聾者 |
| **藏起來** | `dross-kept` | 什麼都沒發生——直到城衛開始查籍 |

**共通觸發**：`ev-guard-census`（城衛查籍）。這是全遊戲第一個**帶致命後果的主線事件**，因此必須有 `tell`（支柱三）：告示牆上早就貼了普查公告，玩家若讀過 `ev-market-noticeboard` 會事先知道。

> **設計要點**：查籍事件不是隨機災難，是**你一直沒處理的問題來收帳**。這正是「每次死亡都要能回溯到一個決定」的敘事版本。

**出章條件**：`ev-guard-census` 已發生。

### 第三章 · 名字（第 8 日起）

三條取得身分的路，**互斥**，各自綁定一名 NPC 與一種代價。

| 路 | NPC | 取得物 | 代價 | 性質 |
| :-- | :-- | :-- | :-- | :-- |
| **A 工牌** | 老克瓦 | 行會臨時工牌 | 要有繭的手：連續工作日數 ＋ 他的信任 | **勞動**：最慢、最穩、最不浪漫 |
| **B 偽籍** | 灰姐 | 冊子上的一行 → 偽造的普查條目 | 錢，以及欠她一件事 | **地下**：最快、要錢、有把柄 |
| **C 擔保** | 石啞 | 寂裔工坊的擔保狀 | 時間與沉默：學會他們的手語 | **同類**：最難、但唯一不需要說謊 |

> **★ C 路的世界觀根據（本作最深的一刀）**：
> `canon/07` §4 判定她是 **0 靈聾／閉血**，且**以任何測法都與土生的閉血者無法區別**。
> 而寂裔**全族**都是 0 靈聾／閉血。
>
> **在這個世界唯一能證明她「是自己人」的東西，恰好是那個讓她永遠不能施法的缺陷。**
> 她的殘疾就是她的護照。這條路不需要偽造任何東西——因為它本來就是真的。

**出章條件**：取得三種身分之一 → 進入第四章（P2）。

## 3 · 關係線

使用者的明確要求：**「我更傾向玩家可以在遊戲中組建友好與戀愛關係」**，且**性只是點綴不是骨架**（`00_pillars.md` 反 DoL 條款二）。

因此關係三軸的定位是：

| 軸 | 意義 | 主要後果 |
| :-- | :-- | :-- |
| `acquaintance` 熟識 | 他認得你的臉 | **機制**：錄取率、開放對話、解鎖地點 |
| `trust` 信任 | 他願意把事情交給你 | **主線**：三條身分路的閘門 |
| `affection` 情感 | 他在意你 | **結局**：安家線的伴侶；平凡線的鄰人 |

### 角色編制

| id | 名 | 位置 | 定位 |
| :-- | :-- | :-- | :-- |
| `npc-quays-foreman` | 老克瓦 | 碼頭 | 師徒／父輩。**非戀愛對象** |
| `npc-cinder-woman` | 灰姐 | 灰棚巷 | 恩人／債主。**非戀愛對象** |
| `npc-grotto-elder` | 石啞 | 石窟街 | 同類／長老。**非戀愛對象** |
| **`npc-market-scribe`** | **穗爾** | 大市集 | **同輩。友情／戀愛可達** |
| **`npc-quays-hand`** | **闕**  | 碼頭 | **同輩。友情／戀愛可達** |

> **為什麼戀愛對象只給同輩、而且給兩個**：
> 一個等於沒得選（是安排不是選擇）；三個以上在 P1 的內容預算下每一條都會變薄。
> 兩個剛好構成一次真正的取捨——而且兩人代表**兩種留下來的方式**：
> 穗爾（識字、市集、往上）與闕（碼頭、體力、往外）。
>
> **戀愛線不開任何機制優勢。** 它只改變結局文本與第四、五章的可用選項。
> 這是反 DoL 條款二的直接落實：把性與戀愛從資源系統裡拿出來。

### 推進節奏

每名 NPC 三階，各階需前一階完成 ＋ 一個門檻：

```
初見（once）→ 熟識 ≥25：日常一幕 → 信任 ≥40 或 情感 ≥30：一件他不對別人說的事
```

**戀愛需玩家主動選擇**：情感達標後出現的事件永遠同時提供「維持朋友」與「更進一步」兩個選項，且前者**不減損任何數值**。

## 5 · 本章不做的事

- **不寫回家的伏筆。** 一個字都不寫。`canon/07` §2 是硬禁止。
- **不讓神說話。** 宗教只是對靈血的詮釋（`canon/00`）。城衛查籍是政體行為，不是神諭。
- **不讓她施法。** 三條身分路沒有任何一條需要她使用靈血能力。
- **不出現第二名活著的現代來客。**（`game/CLAUDE.md` 鐵律 3）
- **不做技術躍進。** 她不會發明任何東西。
