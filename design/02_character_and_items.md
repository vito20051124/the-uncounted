## 1. 角色創建

### 1.1 玩家可選

- **姓名**（自由輸入）
- **外觀**：體型、膚色、髮色與長度、面部特徵、慣用手 —— 純呈現，影響立繪與文字描述
- **性別與代名詞**：女性／男性／**通性**（三者皆可，含代名詞自選）

### 1.2 ★ 性別不開機制分歧（明確裁定）

> **玩家的性別選擇不會改變任何一條規則。**

- 工作表**無性別門檻**——所有工作對所有玩家開放
- 危險度**無性別修正**——街上的風險由地點、時段、路線、聲望決定，不由性別決定
- **所有可攻略 NPC 對所有玩家開放**，戀愛軌不因性別而閉合
- 敘事文本以代名詞替換處理，**不寫兩套分支**

**三個理由，寫明以免日後被當成疏漏：**

1. **這正是使用者拒絕 DoL 的那個東西。** DoL 把性別做成脆弱度系統，使性別成為受害的計量單位。本作把生存壓力放在**經濟**上，不放在身體上。
2. **內容成本減半。** 不寫兩套分支，同樣的預算可以寫兩倍深度。密度是本作對抗 DoL 廣度的唯一武器。
3. **世界仍然有性別。** NPC 有性別，社會有其時代性的紋理，敘事可以呈現這些。**被豁免的是主角的規則，不是世界的質感。**

> **誠實記錄這個抽象的代價**：本作**不模擬**主角所受的時代性性別歧視。這是刻意的取捨，不是遺漏。

### 1.3 不可選（由 `canon-07` 釘死）

- **品階：0 靈聾。體質：閉血。** 永不改變，無覺醒路線。
- **永遠無法接受 `光耀+淨` 治癒。**
- **法律身分：普查未及者。** 不被任何政體登記。

## 2. 死亡與存檔

- **死亡是永久的**：角色死了就是死了，該存檔的旅程結束。
- **但保留 DoL 式的手動存檔**，玩家可自行回檔。**遊戲不強制 Ironman，也不隱藏存檔。**
- **必出死亡回溯畫面**（`00_pillars` 支柱三 / `01_architecture` §7.2）：逐條列出導致死亡的決策鏈，以及每一步當時存在的出口與它們的價格。
  > **即使玩家打算讀檔，也必須先看懂自己是怎麼死的。** 死亡是教學，不是懲罰。

## 3. 開場流程

```
① 角色創建（姓名／外觀／性別代名詞）
        ↓
② 「你肚子餓了。」— 深夜 23:5x，現代世界，自家樓下
        ↓
③ ★ 三樣隨身物選擇（六選三）— 框架是「你出門前順手帶了什麼」，不是裝備欄
        ↓
④ 便利商店。買東西。極短，但這是玩家最後一次看到熟悉的世界
        ↓
⑤ 走出店門。一陣詭異的風。下意識閉眼。
        ↓
⑥ 睜眼 —— 鹵港，某條巷子，夜。
   身上只有 ③ 選的三樣、以及出門時穿的那身衣服。
        ↓
⑦ 教學即生存：第一個晚上就會餓、會冷、會有人經過。沒有引導 NPC。
```

**開場的三條紀律：**

1. **①–④ 必須短。** 現代世界的段落不超過三到四個畫面。它的功能是讓 ⑥ 的落差成立，不是鋪陳。
2. **⑥ 之後不給任何解釋。** 沒有旁白說明她在哪、發生什麼事。**玩家與主角同時無知**，而且會一直無知下去（`canon-07` §1：問「為什麼是我」沒有答案）。
3. **不安排導師。** 沒有人在巷口等她。第一個對她說話的人，動機不一定是善意。

## 4. 三樣隨身物（六選三）

### 4.1 設計框架

這**不是裝備選擇畫面**，是「深夜下樓買宵夜，你身上會有什麼」。六個候選全部是真實會出現在口袋或包裡的東西。

三條共通規則（全部由 `canon-07` §5.1 導出）：

1. **不授予任何超凡能力。** 每樣東西只能做它在原本世界能做的那件平凡的事。
2. **凡消耗品皆嚴格單調遞減，且永不回補。** 電量、燃料、噴射次數、片數——**這個世界沒有任何方法能補充它們**。
3. **對本地人而言，它們與元血之世遺物無法分辨。** 風險等級見下表。

---

### 4.2 六個候選

#### ① 手機 — *一個會用完的光，和一些看一次就少一次的臉*

| 項目 | 內容 |
| :-- | :-- |
| **物理** | 螢幕與閃光燈可照明；可計時；內有相簿。電池不是血晶，靈血梯度對它毫無作用（`canon-07` §5.1.2） |
| **機制** | **照明**：總計約 400 分鐘，可分次使用。夜間路段風險大幅倍增，有光可降低——**這是把危險時段變成可用時段的唯一手段**<br>**計時**：全遊戲唯一精確的時鐘。知道確切時間＝排程優勢（趕得上工班、避得開宵禁）<br>**相簿**：查看可降低壓力（stress）——**但同樣耗電** |
| **耗竭** | 單調遞減，歸零即永久成為一塊光滑的黑色石板 |
| **風險** | **最高。** 發光、會動、材質不明——它是六樣裡最像遺物的東西。被看見＝同時面對灰盟遺物壟斷、歸復教會的異端指控、與關稅查扣三套制度 |
| **★ 設計核心** | **安慰自己是有價格的，而且那個價格不可回收。** 每看一次家人的照片，離「再也看不到」就更近一步。這是本作最殘忍的一條機制，而它完全由 `canon-07` 的物理推導而來 |

#### ② 鑰匙 — *它打不開這裡任何一扇門，但它的鋼比這裡任何一把刀都好*

| 項目 | 內容 |
| :-- | :-- |
| **物理** | 現代精密切削的硬化鋼。**作為鑰匙完全無用**——此世沒有對應的鎖 |
| **機制** | **即興撬鎖**：低成功率，會磨損<br>**★ 材料價值**：均質度是本地冶金做不出來的。鐵匠識貨，願意出價——**但賣掉就沒了**<br>**最後手段**：一小塊尖銳金屬 |
| **耗竭** | 不耗竭，但會磨損；賣掉即永久失去 |
| **風險** | **最低之一。** 它就是一小塊金屬，沒人多看一眼。**但拿去賣會引來鐵匠的追問**——這種鋼是誰做的？ |
| **★ 設計核心** | 唯一一件「它的價值不在功能，在材質」的物品。它逼玩家做一個純粹的取捨：**留著當工具，還是換成活過這週的錢** |

#### ③ 糖果 — *三顆糖，可以是一頓飯，也可以是一個朋友*

| 項目 | 內容 |
| :-- | :-- |
| **物理** | 數顆精製糖果。**精製糖在中世紀經濟中是奢侈品**。包裝紙是此世不可能製造的光滑材質 |
| **機制** | **即時熱量**：少量飽食＋精神安慰<br>**★ 高價交易品**：幾顆糖值得上不少銅<br>**★ 送禮效果異常高**：沒有人吃過這種東西。對關係系統（信任／情感）的推進遠超過其金錢價值 |
| **耗竭** | 吃一顆少一顆，送一顆少一顆 |
| **風險** | **糖本身零風險**（糖不像遺物）。**但包裝紙像。** 丟棄的糖紙是一條會留在原地的線索 |
| **★ 設計核心** | 唯一同時服務**第 1 層（生理）與第 3 層（愛與歸屬）**的物品。玩家必須決定：這幾顆糖是拿來活命，還是拿來交朋友 |

#### ④ 打火機 — *火，在這個世界裡意味著不會凍死、不會拉肚子、不會在黑暗裡走路*

| 項目 | 內容 |
| :-- | :-- |
| **物理** | 無燧生火。燃料嚴格單調遞減 |
| **機制** | **取暖**：體溫是需求之一，**冬天會殺人**<br>**★ 煮沸飲水**：直接、大幅降低疾病判定機率——考量到她永遠不能被治癒，這可能是六樣裡對存活率貢獻最大的一項<br>**照明／烹煮**：省下買燈油與熟食的錢 |
| **耗竭** | 燃料單調遞減。可省著用（生火後保存火種），這本身是一項要學的生活技能 |
| **風險** | **中高，且是最尷尬的一種。** 無燧生火看起來像法術——**但她可被任何測血師驗明為 0 靈聾，物理上不可能施法**。一個不可能施法的人做了看起來像施法的事，那就只剩一個解釋：她身上有遺物 |
| **★ 設計核心** | 對生存幫助最直接、最「不浪漫」的一項。它不解決任何戲劇性的問題，它只是讓你不會死於失溫和痢疾 |

#### ⑤ 防狼噴霧 — *十次，你可以打贏任何一個人。第十一次開始，你只是一個沒有武器的人*

| 項目 | 內容 |
| :-- | :-- |
| **物理** | 約 10 次短噴。**辣椒素在此世不存在**（其原生作物不在此大陸），故該物質對所有人而言是全新的 |
| **機制** | **唯一一件能讓她打贏比她強的人的東西。** 對任何品階的對手都有效（它不是法術，靈血對它無效也無助）<br>但**用一次少一次**，且**用過之後對方會記得她身上有什麼** |
| **耗竭** | 約 10 次，歸零即成為一個空罐 |
| **風險** | **高。** 使用會被視為投毒或煉金術。而且沒有藥師見過辣椒素——**那個空罐子本身會有人想要** |
| **★ 設計核心** | 唯一的「安全感」物品，但它教的是一件殘酷的事：**有限的武力不是安全，只是把問題推遲十次。** 真正的安全來自第 2 層需求（住所、收入、被登記），不來自罐子 |

#### ⑥ OK 繃 — *六樣裡最不起眼的一樣，也是最可能讓你活過第一個月的一樣*

| 項目 | 內容 |
| :-- | :-- |
| **物理** | 一小盒無菌黏性敷料，約 10 片 |
| **機制** | **直接降低感染判定。** 依 `canon-07` §4.1，她永遠不能被 `光耀+淨` 治癒；無魔法可用者的嚴重創傷感染死亡率為 **38.5%**（`hollow-great` 既有數字）。**一片無菌敷料在頭幾週的價值高到不合理** |
| **耗竭** | 一片一次。用完就沒了，且此世造不出無菌敷料 |
| **風險** | **零。** 沒有任何人會多看它一眼 |
| **★ 設計核心** | **它打破了「危險＝強大」的模式。** 它既安全又關鍵，這讓六選三從一根風險/回報滑桿，變成一個真正的決策 |

### 4.3 對照總表

| 物品 | 主要服務的需求層 | 風險 | 耗竭 | 若不選，缺什麼 |
| :-- | :-- | :-- | :-- | :-- |
| 手機 | 1 生理（夜行）＋ 心理 | **極高** | 電量 | 夜晚幾乎不可用；沒有準確時間 |
| 鑰匙 | 2 安全（換錢／工具） | 極低 | 賣即失去 | 少一筆早期啟動資金 |
| 糖果 | 1 生理 ＋ **3 愛與歸屬** | 極低 | 吃／送 | 關係推進慢得多 |
| 打火機 | **1 生理（體溫／飲水）** | 中高 | 燃料 | 冬天與疾病判定明顯惡化 |
| 防狼噴霧 | 2 安全（防身） | 高 | 10 次 | 遇上暴力時沒有任何選項 |
| OK 繃 | **1 生理（傷病）** | **零** | 10 片 | 頭一個月的感染死亡率顯著上升 |

> **★ 設計原則：危險度與實用度大致正相關，但 OK 繃與糖果刻意打破這條線。** 若六樣完全服從「越危險越有用」，選擇就退化成一根滑桿。**兩個例外讓它變成真的選擇。**

## 5. 第四樣你沒得選的東西：身上的衣服

她穿著出門時那身衣服抵達。這**不是一個物品欄位，是一個持續存在的處境**：

- **它本身就是證物。** 布料織法、車縫線、拉鍊、鞋底——沒有一樣是此世做得出來的。穿著它走在鹵港，等於一路在展示自己的來歷。
- **它會壞。** 沒有替換品，沒有同樣的材質可以補。
- **★ 換上本地衣物是一個可見的里程碑。** 那一刻她不再是「一個穿著怪衣服的外地人」，而是「一個沒有人在數的人」——**從顯眼的異類，降級為隱形的窮人。這是進步。**

> 這條把 `00_pillars` 的第 2 層需求（安全）具象化了：**融入不是被接納，是不再被注意。**
